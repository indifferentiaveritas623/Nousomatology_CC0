## Getting Started

### Prerequisites
To clone and work with this repository locally, you will need:
* **Git** installed on your machine

### Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd Nousomatology_CC0
   ```
